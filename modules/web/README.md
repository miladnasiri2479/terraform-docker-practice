# ماژول وب (Web Module)

این ماژول وظیفه ایجاد کلاستر وب‌سرورهای Nginx را به صورت مقیاس‌پذیر (Scalable) بر عهده دارد.

## منابع (Resources)

- **docker_image.nginx**: دریافت Image رسمی Nginx نسخه Alpine (سبک و بهینه).
- **docker_container.web**: ایجاد تعدادی کانتینر وب بر اساس متغیر `web_count`. 
    - استفاده از `for_each` برای مدیریت دقیق‌تر هر کانتینر.
    - تنظیم پورت‌های خروجی به صورت داینامیک.
    - **Healthcheck**: بررسی مداوم سلامت کانتینر؛ اگر سرویس Nginx پاسخگو نباشد، داکر وضعیت کانتینر را به `unhealthy` تغییر می‌دهد.

## متغیرها (Variables)

- **web_count**: تعداد کانتینرهایی که باید ساخته شوند (حداقل ۱ عدد).
- **web_container_prefix**: پیشوند نام کانتینرها.
- **network_name**: نام شبکه‌ای که کانتینرها به آن وصل می‌شوند.
- **external_port_start**: شماره پورت شروع برای مپ کردن به پورت ۸۰ داخلی.

## خروجی‌ها (Outputs)

- **web_ips**: لیست IPهای داخلی تمامی کانتینرهای وب.
- **web_urls**: لیست URLهای دسترسی به کانتینرها (مثلاً `http://localhost:8080`).
