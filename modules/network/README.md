# ماژول شبکه (Network Module)

این ماژول وظیفه ایجاد و مدیریت شبکه داخلی داکر را بر عهده دارد تا سایر کانتینرها بتوانند با یکدیگر ارتباط برقرار کنند.

## منابع (Resources)

- **docker_network.app_network**: ایجاد یک شبکه از نوع `bridge` در داکر. نام این شبکه از متغیر ورودی گرفته می‌شود تا در محیط‌های مختلف (Dev/Prod) ایزوله بماند.

## متغیرها (Variables)

- **network_name**: نام شبکه برای ایجاد در داکر.

## خروجی‌ها (Outputs)

- **network_name**: نام شبکه ایجاد شده (برای استفاده در ماژول‌های دیگر).
